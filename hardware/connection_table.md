Универсальная плата для снifferа/эмитера TPMS на базе ESP8266 D1 Mini или ESP32-C3 Mini с модулем CC1101 на 315 МГц.

**Формула делителя:**
```
Vbat = ADC_reading × (R1 + R2) / R2
Vbat = ADC_reading × (10000 + 10000) / 10000
Vbat = ADC_reading × 2
```

### Подключение CC1101 к ESP8266

| Функция         | ESP8266 Pin | CC1101 Pin | Сеть           | Примечание                      |
|-----------------|-------------|------------|----------------|---------------------------------|
| MOSI            | D7 (GPIO13) | SI/DIN     | SPI_MOSI       | Ввод данных                     |
| MISO            | D6 (GPIO12) | SO/DOUT    | SPI_MISO       | Вывод данных                    |
| CLK             | D5 (GPIO14) | CLK        | SPI_CLK        | Тактирование SPI                |
| CS              | D8 (GPIO15) | CSN        | SPI_CS         | Выбор ведомого (ACTIVE LOW)     |
| GDO0            | D1 (GPIO5)  | GDO0       | GDO0           | Прерывание/данные              |
| GDO2            | D2 (GPIO4)  | GDO2       | GDO2           | Прерывание/данные              |
| PWR (N-MOSFET) | D4 (GPIO2)  | GND        | CC1101 GND     | Управление питанием (N-MOSFET) |
| GND             | GND         | GND        | GND             | Общая земля                     |

**Цепь управления питанием CC1101 (ESP8266):**
```
D4 (GPIO2) → R (1кОм) → Затвор 2N7002
Источник 2N7002 → GND
Сток 2N7002 → CC1101 GND
CC1101 GND → GND
```

## Диаграмма управления питанием CC1101

### Для ESP8266 (через N-MOSFET low-side):
```
D4 (GPIO2) ────[R 1кОм]────┐
                            │
                       ┌────┴────┐
                       │  2N7002  │  N-MOSFET
                       │(SOT-23) │
                       └────┬────┘
                            │
CC1101 GND ◄────────────────┘
                            │
GND ◄───────────────────────┘

CC1101 VCC ──────── VCC_3V3 (3.3V, всегда подключено)
```

**Логика:** D4 = HIGH → 2N7002 ON → CC1101 GND подключена → модуль работает

### Для ESP32-C3 (прямое управление):
```
GPIO6 ────────────────────────────► CC1101 VCC
```

## Примечания

1. **Земляной проводник:** Все компоненты подключаются к общей земле (GND). Рекомендуется использовать звезду земли или широкие дорожки.

2. **Конденсаторы:** Входной и выходной конденсаторы AMS1117 обязательны. Конденсаторы ESP и CC1101 должны быть как можно ближе к выводам питания.

3. **Разделители:** R1 и R2 должны быть точностью 1% для точного измерения напряжения батареи.

4. **Ток потребления:**
   - ESP8266: ~80 мА (WiFi), ~20 мА (sleep)
   - ESP32-C3: ~35 мА (WiFi), ~5 мА (sleep)
   - CC1101: ~30 мА (RX/TX), ~1 мА (idle)

5. **Защита:** TP4056 с DW01+FS8205 обеспечивает защиту от перезаряда, переразряда и короткого замыкания.

6. **Максимальный ток AMS1117:** 800 мА (достаточно для ESP + CC1101).
