# Пайка CC1101 к ProMicro nRF52840 V1940 (Nice!Nano clone)

## Физические метки пинов на плате

На плате ProMicro nRF52840 V1940 пины промаркированы как **P0.xx** и **P1.xx** (например, "006", "029", "113"). В прошивке используются Arduino D-номера Feather-варианта, которые маппятся на эти P0.xx/P1.xx пины.

| Функция в прошивке | Feather D-номер | P0.xx / P1.xx | **Метка на плате** |
|---------------------|-----------------|---------------|---------------------|
| SPI MISO            | D46             | P0.29         | **029**             |
| SPI MOSI            | D48             | P0.31         | **031**             |
| SPI SCK             | D3              | P1.04         | **104**             |
| CC1101 CS           | D25             | P0.06         | **006**             |
| CC1101 GDO0         | D27             | P0.08         | **008**             |
| CC1101 GDO2         | D10             | P1.13         | **113**             |
| CC1101 POWER        | D8              | P1.11         | **111**             |
| Status LED          | D12             | P1.15         | **115**             |
| Battery ADC         | 2               | P0.02         | **002** (AIN0)      |

## Управление питанием (опционально)

В прошивке есть пин `CC1101 POWER` = D8 (P1.11, метка **111**). CC1101 в режиме TX может потреблять 15–40 мА, что больше допустимого для GPIO nRF52840 (~8–10 мА). Поэтому:

- **Простой вариант:** подключи VCC CC1101 напрямую к 3.3V платы. CC1101 всё время включён.
- **Вариант с управлением:** используй пин **111** (D8, P1.11) для управления MOSFET/транзистором, который подаёт 3.3V на VCC CC1101. Тогда прошивка сможет включать/выключать модуль программно.

## Проверка после пайки

1. Прошей плату актуальной `.uf2`.
2. Открой Android-приложение — оно автоматически подключится к сопряжённому `TPMS-NRF52840`.
3. Включи CC1101 (если используешь управление питанием) тогглом **Power** в приложении.
4. Нажми **Burst** — плата должна отправить TPMS-пакеты. Для проверки можно использовать другой приёмник или сниффер.

## Частоты

- 315 МГц — по умолчанию в прошивке.
- 433 МГц — переключается в приложении кнопкой **433**.

## Примечание про антенну

CC1101 требуется внешняя антенна (подпаянная к пину ANT или через SMA/U.FL). Без антенны модуль может повредиться при передаче.

## Важно: доступные пины на плате

На плате ProMicro nRF52840 V1940 доступны следующие пины (с физическими метками):

**P0.xx пины:** 002, 006, 008, 010, 017, 020, 022, 024, 029, 031
**P1.xx пины:** 100, 101, 102, 104, 111, 113, 115

Из них в Feather-варианте есть Arduino D-номера:
- P0.06=D25, P0.08=D27, P0.17=D34, P0.20=D37, P0.22=D39, P0.24=D41, P0.29=D46, P0.31=D48
- P1.01=D0, P1.02=D1, P1.04=D3, P1.11=D8, P1.13=D10, P1.15=D12

**P0.02, P0.10, P1.00** — доступны на плате, но **не имеют D-номеров** в Feather-варианте. Для них нужно использовать прямой доступ к регистрам NRF_P0/NRF_P1.
