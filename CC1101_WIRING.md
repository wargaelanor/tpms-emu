# Пайка CC1101 к ProMicro nRF52840 V1940

## Пиновая распиновка

| CC1101 модуль | ProMicro nRF52840 | nRF52840 GPIO | Примечание |
|---------------|-------------------|---------------|------------|
| VCC (3.3V)    | 3.3V / VCC        | —             | Питание модуля (см. ниже про управление питанием) |
| GND           | GND               | —             | Общий минус |
| SCK           | D21               | P0.31         | SPI SCK |
| MISO / SO     | D17               | P0.28         | SPI MISO |
| MOSI / SI     | D20               | P0.29         | SPI MOSI |
| CSN / CS      | D10               | P0.27         | Chip Select |
| GDO0          | D11               | P0.06         | TX/RX индикатор пакета |
| GDO2          | D12               | P0.08         | RX FIFO threshold |

> **Важно:** Пины SPI изменены с дефолтных, чтобы не конфликтовать со светодиодом на D24 (P0.15), который в варианте Feather является дефолтным SPI MISO.

## Схема подключения (ASCII)

```
        CC1101                  ProMicro nRF52840 V1940
        ┌─────────┐             ┌─────────────────────────┐
        │         │             │                         │
VCC  ───┤VCC      │             │  3.3V / VCC             │
        │         │             │                         │
GND  ───┤GND      │             │  GND                    │
        │         │             │                         │
SCK  ───┤SCK      │─────────────┤  D21  (P0.31)           │
        │         │             │                         │
MISO ───┤MISO/SO  │─────────────┤  D17  (P0.28)           │
        │         │             │                         │
MOSI ───┤MOSI/SI  │─────────────┤  D20  (P0.29)           │
        │         │             │                         │
CSN  ───┤CSN      │─────────────┤  D10  (P0.27)           │
        │         │             │                         │
GDO0 ───┤GDO0     │─────────────┤  D11  (P0.06)           │
        │         │             │                         │
GDO2 ───┤GDO2     │─────────────┤  D12  (P0.08)           │
        │         │             │                         │
        └─────────┘             │  D24  (P0.15) — LED     │
                              └─────────────────────────┘
```

## Управление питанием (опционально)

В прошивке есть пин `CC1101 POWER` = D9 (P0.26). CC1101 в режиме TX может потреблять 15–40 мА, что больше допустимого для GPIO nRF52840 (~8–10 мА). Поэтому:

- **Простой вариант:** подключи VCC CC1101 напрямую к 3.3V платы. CC1101 всё время включён.
- **Вариант с управлением:** используй пин D9 (P0.26) для управления MOSFET/транзистором, который подаёт 3.3V на VCC CC1101. Тогда прошивка сможет включать/выключать модуль программно.

## Проверка после пайки

1. Прошей плату актуальной `.uf2`.
2. Открой Android-приложение — оно автоматически подключится к сопряжённому `TPMS-NRF52840`.
3. Включи CC1101 (если используешь управление питанием) тогглом **Power** в приложении.
4. Нажми **Burst** — плата должна отправить TPMS-пакеты. Для проверки можно использовать другой приёмник или сниффер.

## Частоты

- 315 МГц — по умолчанию в прошивке.
- 433 МГц — переключается в приложении кнопкой **433**.

## Примечание про антенну

CC1101 требуется внешняя антенна (подпаянная к пину ANT или через SMA/U.FL). Без антенны модуль может повредиться при передаче.
