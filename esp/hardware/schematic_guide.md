# Руководство по схемотехнике в EasyEDA

## Назначение
Пошаговое руководство для разводки схемы универсальной платы TPMS в EasyEDA (Standard или Pro).

## Подготовка

### Создание нового проекта
1. Откройте EasyEDA (https://easyeda.com)
2. Создайте новый проект: **File → New → Project**
3. Назовите проект: `TPMS_Universal_Board`
4. Создайте новый лист схемы: **Schematic**

### Настройка листа
1. **File → Sheet Settings**
2. Формат: **A3** (для удобства размещения)
3. Единицы: **mm**
4. Стандарт: **ANSI**

## Порядок размещения компонентов

### Шаг 1: Размещение силового тракта

#### 1.1 Разъем Micro-USB (TP4056 модуль)
1. Поиск в библиотеке: `USB Micro` или `TP4056 Module`
2. Разместите в левом верхнем углу схемы
3. Выводы:
   - `VBUS` → к входу TP4056
   - `GND` → общая земля
   - `D+`, `D-` → не подключаются (только питание)

#### 1.2 TP4056 модуль с защитой
1. Поиск: `TP4056 DW01 FS8205` или `Li-Ion Charger Module`
2. Разместите справа от Micro-USB
3. Подключите:
   - `IN+` → `VBUS` от USB
   - `IN-` → `GND`
   - `B+` → `+` аккумулятора
   - `B-` → `-` аккумулятора
   - `OUT+` → `VCC_SYS`
   - `OUT-` → `GND`

#### 1.3 Держатель аккумулятора 18650
1. Поиск: `Battery Holder 18650`
2. Разместите слева от TP4056
3. Подключите:
   - `+` → `B+` TP4056
   - `-` → `B-` TP4056

#### 1.4 Переключатель SPDT
1. Поиск: `Switch SPDT` или `Slide Switch`
2. Разместите справа от TP4056
3. Подключите:
   - `COM` → `OUT+` TP4056 (VCC_SYS)
   - `NO` → `VIN` AMS1117
   - `NC` → не подключается

#### 1.5 Стабилизатор AMS1117-3.3
1. Поиск: `AMS1117-3.3` или `Voltage Regulator 3.3V`
2. Разместите в центре верхней части
3. Подключите:
   - `VIN` → `NO` переключателя
   - `GND` → общая земля
   - `VOUT` → `VCC_3V3`
   - `Tab` → `GND` (для охлаждения)

#### 1.6 Конденсаторы стабилизации
1. Поиск: `Capacitor 100nF` и `Capacitor 10uF`
2. Разместите:
   - `C1 100нФ` между `VIN` AMS1117 и GND
   - `C2 10мкФ` между `VOUT` AMS1117 и GND
   - `C3 100нФ` между `VCC_3V3` ESP и GND
   - `C4 100нФ` между `CC1101_VCC` и GND

### Шаг 2: Размещение микроконтроллеров

#### 2.1 ESP8266 D1 Mini
1. Поиск: `ESP8266 D1 Mini` или `WeMos D1 Mini`
2. Разместите в правой части схемы
3. Добавьте пиновый разъем 2x8:
   - Поиск: `Pin Header 2x8 2.54mm`
   - Разместите рядом с ESP8266

#### 2.2 ESP32-C3 Mini
1. Поиск: `ESP32-C3` или `ESP32-C3-MINI-1`
2. Разместите ниже ESP8266
3. Добавьте пиновый разъем 2x10:
   - Поиск: `Pin Header 2x10 2.54mm`
   - Разместите рядом с ESP32-C3

#### 2.3 Jumper-перемычки для выбора платы
1. Поиск: `Jumper 2-pin` или `Header 2-pin`
2. Разместите 4 джампера:
   - `JP1`: Выбор ESP (ESP8266/ESP32-C3)
   - `JP2`: Deep sleep (только ESP8266)
   - `JP3`: Режим CC1101 PWR
   - `JP4`: Режим ADC

### Шаг 3: Размещение CC1101

#### 3.1 Модуль CC1101
1. Поиск: `CC1101 Module` или `CC1101 315MHz`
2. Разместите в центре схемы
3. Добавьте пиновый разъем 1x8:
   - Поиск: `Pin Header 1x8 2.54mm`
   - Разместите рядом с CC1101

#### 3.2 Подключение CC1101
1. Соедините выводы CC1101 с соответствующими сетями:
   - `VCC` → `CC1101_VCC`
   - `GND` → `GND`
   - `SI/DIN` → `SPI_MOSI`
   - `SO/DOUT` → `SPI_MISO`
   - `CLK` → `SPI_CLK`
   - `CSN` → `SPI_CS`
   - `GDO0` → `GDO0`
   - `GDO2` → `GDO2`

### Шаг 4: Размещение цепей управления

#### 4.1 Цепь управления питанием CC1101 (ESP8266)
1. Поиск: `2N7002` (N-MOSFET, SOT-23)
2. Разместите рядом с ESP8266
3. Подключите:
   - `Gate` → через R 1кОм к `D4 (GPIO2)`
   - `Source` → `GND`
   - `Drain` → `CC1101_VCC`

#### 4.2 Разделитель напряжения батареи
1. Разместите 2 резистора 10кОм:
   - `R1`: между `VCC_SYS` и `ADC_BAT`
   - `R2`: между `ADC_BAT` и `GND`
2. Добавьте конденсатор 100нФ параллельно R2

#### 4.3 Цепь глубокого сна (ESP8266)
1. Разместите:
   - Резистор 10кОм: `RST` → `VCC_3V3`
   - Кнопка: `RST` → `GND`
   - Jumper JP2: `D0 (GPIO16)` → `RST`

### Шаг 5: Размещение индикации

#### 5.1 Светодиоды
1. Поиск: `LED 0805`
2. Разместите 3 светодиода:
   - Зеленый: `Power` (постоянно горит)
   - Красный: `Charge` (горит при зарядке)
   - Синий: `Status` (управление от ESP)

#### 5.2 Резисторы для LED
1. Разместите 3 резистора 1кОм последовательно с каждым LED

### Шаг 6: Размещение разъемов

#### 6.1 GPIO разъемы
1. Поиск: `Pin Header 2.54mm`
2. Разместите:
   - 1x8 для CC1101
   - 2x8 для ESP8266 D1 Mini
   - 2x10 для ESP32-C3

#### 6.2 Кнопка сброса
1. Поиск: `Tactile Switch 6x6mm`
2. Разместите рядом с ESP8266

## Порядок соединения (Net Connections)

### Шаг 1: Силовые соединения

#### 1.1 Питание аккумулятора
1. `Battery+` → `TP4056 B+`
2. `Battery-` → `TP4056 B-`
3. `TP4056 OUT+` → `SPDT COM`
4. `TP4056 OUT-` → `GND`

#### 1.2 Питание 3.3В
1. `SPDT NO` → `AMS1117 VIN`
2. `AMS1117 GND` → `GND`
3. `AMS1117 VOUT` → `VCC_3V3`
4. `VCC_3V3` → `ESP8266 3V3` (через JP1)
5. `VCC_3V3` → `ESP32-C3 3V3` (через JP1)

#### 1.3 Питание CC1101
1. `VCC_3V3` → `CC1101 VCC` (всегда подключено)
2. `CC1101 GND` → `2N7002 Drain` (через JP3)
3. `ESP32-C3 GPIO6` → `CC1101 VCC` (через JP3)

### Шаг 2: Земляные соединения

1. `TP4056 GND` → `GND`
2. `AMS1117 GND` → `GND`
3. `ESP8266 GND` → `GND`
4. `ESP32-C3 GND` → `GND`
5. `CC1101 GND` → `GND`
6. `2N7002 Source` → `GND`
7. `Battery-` → `GND`

### Шаг 3: SPI соединения

#### 3.1 Для ESP8266
1. `ESP8266 D7 (GPIO13)` → `SPI_MOSI`
2. `ESP8266 D6 (GPIO12)` → `SPI_MISO`
3. `ESP8266 D5 (GPIO14)` → `SPI_CLK`
4. `ESP8266 D8 (GPIO15)` → `SPI_CS`
5. `SPI_MOSI` → `CC1101 SI/DIN`
6. `SPI_MISO` → `CC1101 SO/DOUT`
7. `SPI_CLK` → `CC1101 CLK`
8. `SPI_CS` → `CC1101 CSN`

#### 3.2 Для ESP32-C3
1. `ESP32-C3 GPIO1` → `SPI_MOSI`
2. `ESP32-C3 GPIO3` → `SPI_MISO`
3. `ESP32-C3 GPIO2` → `SPI_CLK`
4. `ESP32-C3 GPIO7` → `SPI_CS`
5. `SPI_MOSI` → `CC1101 SI/DIN`
6. `SPI_MISO` → `CC1101 SO/DOUT`
7. `SPI_CLK` → `CC1101 CLK`
8. `SPI_CS` → `CC1101 CSN`

### Шаг 4: Управление питанием CC1101

#### 4.1 Через N-MOSFET (ESP8266) — low-side switch
1. `ESP8266 D4 (GPIO2)` → `R 1кОм` → `2N7002 Gate`
2. `2N7002 Source` → `GND`
3. `2N7002 Drain` → `CC1101 GND`
4. `CC1101 VCC` → `VCC_3V3` (всегда подключено)

**Логика:** D4 = HIGH → 2N7002 ON → CC1101 GND подключена → модуль работает

#### 4.2 Прямое управление (ESP32-C3)
1. `ESP32-C3 GPIO6` → `CC1101 VCC`

### Шаг 5: Аналоговые соединения

#### 5.1 Делитель напряжения
1. `VCC_SYS` → `R1 10кОм` → `ADC_BAT`
2. `ADC_BAT` → `R2 10кОм` → `GND`
3. `ADC_BAT` → `C 100нФ` → `GND`
4. `ADC_BAT` → `ESP8266 A0` (через JP4)
5. `ADC_BAT` → `ESP32-C3 GPIO0` (через JP4)

### Шаг 6: Цепь GDO

1. `CC1101 GDO0` → `GDO0`
2. `CC1101 GDO2` → `GDO2`
3. `GDO0` → `ESP8266 D1 (GPIO5)`
4. `GDO0` → `ESP32-C3 GPIO4`
5. `GDO2` → `ESP8266 D2 (GPIO4)`
6. `GDO2` → `ESP32-C3 GPIO5`

### Шаг 7: Цепь глубокого сна

1. `ESP8266 D0 (GPIO16)` → `JP2 pin 1`
2. `JP2 pin 2` → `RST`
3. `RST` → `R 10кОм` → `VCC_3V3`
4. `RST` → `Кнопка` → `GND`

### Шаг 8: Светодиоды

1. `VCC_3V3` → `R 1кОм` → `Green LED+` → `Green LED-` → `GND`
2. `VCC_BAT` → `R 1кОм` → `Red LED+` → `Red LED-` → `GND`
3. `ESP8266 D3 (GPIO0)` → `R 1кОм` → `Blue LED+` → `Blue LED-` → `GND`

## Правила разводки (Design Rules)

### Минимальные размеры
1. **Ширина дорожки питания:** 0.5 мм (20 миль)
2. **Ширина сигнальных дорожек:** 0.25 мм (10 миль)
3. **Расстояние между дорожками:** 0.25 мм (10 миль)
4. **Размер падов:** 1.5 мм (60 миль)
5. **Размер отверстий:** 0.3 мм (12 миль)

### Рекомендации по разводке
1. **Питание:** Используйте широкие дорожки (0.5-1.0 мм) для силовых цепей
2. **Земля:** Сделайте сплошной слой земли (Ground Plane)
3. **SPI:** Держите SPI линии как можно короче и вместе
4. **Аналог:** Изолируйте аналоговые цепи от цифровых
5. **Конденсаторы:** Размещайте конденсаторы как можно ближе к выводам питания

## PCB Layout Tips

### Шаг 1: Подготовка
1. **Design → Layer Stack Manager**
   - Слои: 2 (Top + Bottom)
   - Толщина: 1.6 мм
   - Медный слой: 35 мкм (1 унция)

2. **Design → Design Rules**
   - Минимальная ширина дорожки: 0.25 мм
   - Минимальное расстояние: 0.25 мм
   - Минимальный размер пада: 1.5 мм

### Шаг 2: Размещение компонентов

#### 2.1 Силовой тракт (верхняя часть)
1. Micro-USB разъем: левый верхний угол
2. TP4056 модуль: справа от USB
3. Держатель 18650: левый верхний угол (под USB)
4. SPDT переключатель: правее TP4056
5. AMS1117: центр верхней части

#### 2.2 Микроконтроллеры (правая часть)
1. ESP8266: правая верхняя часть
2. ESP32-C3: правая нижняя часть
3. Пиновые разъемы: рядом с соответствующими ESP

#### 2.3 Радиомодуль (центр)
1. CC1101: центр платы
2. Пиновый разъем 1x8: рядом с CC1101

#### 2.4 Вспомогательные компоненты
1. Резисторы и конденсаторы: вокруг соответствующих цепей
2. Светодиоды: край правой части
3. Кнопка сброса: рядом с ESP8266

### Шаг 3: Разводка дорожек

#### 3.1 Силовые дорожки (Top Layer)
1. `VCC_SYS` → `AMS1117 VIN`: 1.0 мм
2. `VCC_3V3` → `ESP 3V3`: 0.8 мм
3. `CC1101_VCC`: 0.5 мм
4. `GND`: сплошной слой

#### 3.2 SPI дорожки (Top Layer)
1. `SPI_MOSI`: 0.3 мм
2. `SPI_MISO`: 0.3 мм
3. `SPI_CLK`: 0.3 мм
4. `SPI_CS`: 0.3 мм
5. Длина: ≤ 50 мм, одинаковая

#### 3.3 Аналоговые дорожки (Top Layer)
1. `ADC_BAT`: 0.3 мм
2. Экранирование от цифровых сигналов

#### 3.4 Управляющие дорожки (Bottom Layer)
1. `GDO0`, `GDO2`: 0.3 мм
2. `PWR_CC1101`: 0.3 мм
3. `DEEP_SLEEP`: 0.3 мм

### Шаг 4: Заземление

#### 4.1 Ground Plane (Bottom Layer)
1. **Tools → Pour Area**
2. Выберите Bottom Layer
3. Нет: `GND`
4. Ширина заливки: 0.5 мм
5. Расстояние от дорожек: 0.3 мм

#### 4.2 Thermal Relief
1. Для компонентов с большим током: прямое подключение к земле
2. Для остальных: thermal relief (4 spoke)

### Шаг 5: Маркировка

#### 5.1 Текстовые метки
1. Добавьте названия сетей на Top Silk
2. Добавьте обозначения компонентов
3. Добавьте логотип проекта

#### 5.2 Маркировка jumper-перемычек
1. `JP1`: "ESP8266 | ESP32-C3"
2. `JP2`: "DEEP SLEEP"
3. `JP3`: "N-MOSFET | DIRECT"
4. `JP4`: "A0 | GPIO0"

## Проверка схемы

### ERC (Electrical Rules Check)
1. **Design → Check ERC**
2. Исправьте все ошибки:
   - Неподключенные выводы
   - Конфликты питания
   - Отсутствующие значения

### DRC (Design Rules Check)
1. **Design → Check DRC**
2. Исправьте все ошибки:
   - Слишком короткие дорожки
   - Слишком близкие дорожки
   - Неправильные размеры падов

## Экспорт файлов

### Gerber файлы
1. **Fabrication → PCB Fabrication File (Gerber)**
2. Выберите все слои
3. Формат: **Gerber RS-274X**
4. Сохраните в папку `hardware/gerber/`

### BOM (Список компонентов)
1. **Fabrication → BOM**
2. Формат: **CSV**
3. Сохраните в папку `hardware/bom/`

### Pick and Place файл
1. **Fabrication → Pick and Place File**
2. Формат: **CSV**
3. Сохраните в папку `hardware/pnp/`

## Тестирование платы

### До пайки
1. Проверьте дорожки мультиметром на короткое замыкание
2. Проверьте целостность всех дорожек

### После пайки
1. **Без аккумулятора:** Подключите USB, проверьте 5В на TP4056
2. **С аккумулятором:** Проверьте зарядку (красный LED)
3. **Включите питание:** Проверьте 3.3В на AMS1117
4. **ESP8266:** Загрузите прошивку, проверьте WiFi
5. **ESP32-C3:** Загрузите прошивку, проверьте WiFi
6. **CC1101:** Проверьте SPI связь
7. **ADC:** Проверьте измерение напряжения батареи
