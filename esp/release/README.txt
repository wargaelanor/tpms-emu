========================================
  TPMS Emulator v7.2 - ESP32-C3 + CC1101
========================================

Проект: Эмулятор/сниффер датчиков давления в шинах (TPMS)
Протокол: PMV-107J (Pacific Industrial) - rtl_433 protocol 110
Частоты: 315 MHz / 433.92 MHz (переключаемая через web)
Платформа: ESP32-C3 Super Mini + CC1101 8-pin модуль

========================================
  ВОЗМОЖНОСТИ v7.2
========================================

- **Эмулятор TPMS** — передача пакетов PMV-107J для 4 датчиков
- **Сниффер TPMS** — приём и декодирование реальных датчиков
  - Continuous RX, RSSI-фильтр, авто-декодирование
  - Авто-остановка при нахождении всех 4 датчиков + сохранение в EEPROM
  - Запуск только по кнопке (не стартует автоматически)
- **Лицензирование** — программная защита
  - 24 часа пробного периода (считает активное время + глубокий сон)
  - После пробного периода сниффер отключается
  - Постоянная лицензия через HMAC-SHA256 ключ (Device ID + keygen.py)
  - EEPROM сохраняет состояние лицензии (не сбрасывается перезагрузкой)
- **Web-интерфейс** — адаптивный, управление через браузер
  - Карточки датчиков с иконками колёс
  - Настройка частоты (315/433 МГц) и мощности PA
  - Auto-TX с настраиваемым интервалом
  - Калькулятор времени работы от батареи 600 мА·ч
  - Карточка лицензии: Device ID, ввод ключа, статус
- **Deep Sleep** — ~7 мкА в сне, пробуждение по таймеру
- **CC1101 прямое питание с GPIO** — без MOSFET

========================================
  КОМПЛЕКТУЮЩИЕ
========================================

1. ESP32-C3 Super Mini (RISC-V, WiFi, BLE)
   - Встроенный USB-Serial
   - 4MB Flash, 320KB RAM

2. CC1101 8-pin модуль (Sub-GHz трансивер)
   - Частота: 315 MHz или 433 MHz (смотреть маркировку на корпусе)
   - Кристалл: 26.000 MHz
   - Антенна: комплектная (под частоту модуля)

3. Антенна SDR (для приёма/проверки)
   - RTL-SDR v3 с антенной на 315/433 MHz
   - Программа: rtl_433 или SDRSharp

========================================
  ПОДКЛЮЧЕНИЕ (ESP32-C3 -> CC1101)
========================================

CC1101 Pin 1 (VCC)  -> GPIO6 (питание от GPIO!)
CC1101 Pin 2 (GND)  -> GND ESP32-C3
CC1101 Pin 3 (SI)   -> GPIO1 (MOSI)
CC1101 Pin 4 (SO)   -> GPIO3 (MISO)
CC1101 Pin 5 (CLK)  -> GPIO2 (SCK)
CC1101 Pin 6 (CSN)  -> GPIO7 (CS)
CC1101 Pin 7 (GDO0) -> GPIO4
CC1101 Pin 8 (GDO2) -> GPIO5

ВАЖНО: CC1101 VCC подключен к GPIO6!
  - GPIO HIGH = CC1101 ON
  - GPIO LOW  = CC1101 OFF (deep sleep)

Цветовая маркировка проводов:
  Красный    - GPIO6 -> VCC
  Чёрный     - GND -> GND
  Синий      - GPIO1 -> SI (MOSI)
  Зелёный    - GPIO3 -> SO (MISO)
  Оранжевый  - GPIO2 -> CLK (SCK)
  Фиолетовый - GPIO7 -> CSN
  Коричневый - GPIO4 -> GDO0
  Голубой    - GPIO5 -> GDO2

Вариант 0: Графическая утилита (Windows, рекомендуется)
  double-click flash_gui.pyw

  pio run --target upload

  С шифрованием (требует platformio.ini):
  pio run --target upload --env release

Вариант 3: Вручную через esptool
  esptool.py --chip esp32c3 --port COM8 write_flash -z \
    0x0000 bootloader.bin \
    0x8000 partitions.bin \
    0x10000 firmware.bin

  С шифрованием:
  esptool.py --chip esp32c3 --port COM8 write_flash -z --encrypt \
    0x0000 bootloader.bin \
    0x8000 partitions.bin \
    0x10000 firmware.bin

========================================
  ЗАЩИТА ОТ КОПИРОВАНИЯ (Flash Encryption)
========================================

Flash Encryption шифрует прошивку аппаратным ключом в eFuse.
Даже при выпайке flash-памяти данные невозможно прочитать.

ВАЖНО: Процесс НЕОБРАТИМ. После активации чип принимает
только зашифрованную прошивку.

Пошаговая инструкция:

Шаг 1. Сгенерировать ключ (один раз на партию устройств):
  python generate_key.py
  → создаёт flash_encryption_key.bin

Шаг 2. Прошить ПЕРВЫЙ раз (прожигает eFuse!):
  python flash.py --encrypt --keyfile flash_encryption_key.bin

Шаг 3. Последующие прошивки того же чипа:
  python flash.py --encrypt --keyfile flash_encryption_key.bin

  Или подготовить зашифрованный бинарник (без чипа):
  python flash.py --encrypt-offline --keyfile flash_encryption_key.bin

  Полученный firmware_encrypted.bin можно заливать на любой
  чип из партии той же командой flash.py с флагом --encrypt.

ВАЖНО: Храните flash_encryption_key.bin в НЕДОСТУПНОМ месте!
  - Без ключа невозможно прошить чип после активации
  - Не храните ключ в git-репозитории!

========================================
  ЛИЦЕНЗИРОВАНИЕ (v7.2)
========================================

Устройство имеет 24 часа пробного периода.
Таймер считает общее время работы (активность + глубокий сон).
Сохраняется в EEPROM и НЕ сбрасывается при перезагрузке/отключении питания.

После пробного периода сниффер блокируется.
Эмулятор (Auto-TX) работает без ограничений.

Для постоянной активации:
1. Открыть веб-интерфейс → карточка "Лицензия"
2. Скопировать Device ID (12 символов)
3. Отправить на wargaelanor@yandex.ru
4. Получить 8-символьный ключ
5. Ввести ключ в поле и нажать "Активировать"

Генерация ключа (для изготовителя):
  python keygen.py <DEVICE_ID>
  → выводит 8-символьный ключ

========================================
  ИСПОЛЬЗОВАНИЕ
========================================

1. Прошить ESP32-C3
2. Подключиться к WiFi: TPMS (пароль: 12345678)
3. Открыть: http://192.168.4.1
4. Настроить датчики (ID, давление, температура)
5. Выбрать частоту: 315 или 433 MHz
6. Нажать "Применить"
7. Для поиска реальных датчиков — нажать "Старт" в карточке сниффера

По умолчанию:
  - Частота: 315 MHz
  - Давление: 230 kPa (~33 PSI)
  - Температура: 20 C
  - Auto-TX: каждые 5 минут

========================================
  ПРОВЕРКА ЧЕРЕЗ rtl_433
========================================

315 MHz:
  rtl_433 -f 315M -R 110 -R 181

433 MHz:
  rtl_433 -f 433.92M -R 110 -R 181

Ожидаемые ID датчиков (по умолчанию):
  00298088, 0466E088, 0D784088, 0C765088

========================================
  ГЛУБОКИЙ СОН (Deep Sleep)
========================================

ESP32-C3 переходит в deep sleep через 3 минуты
без активных подключений. Пробуждается каждые
5 минут для отправки burst.

При открытой веб-странице ESP НЕ уходит в сон
(таймаут сбрасывается при HTTP/WS активности).
