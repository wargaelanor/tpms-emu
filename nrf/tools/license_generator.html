Генератор ключа лицензии

TPMS-NRF52840 · ключ привязан к серийнику конкретного устройства

1. Вставь серийный номер из письма клиента (поле «ID устройства»).
2. Ключ = формула из прошивки (FICR DEVICEID + секретная формула).
3. Отправь полученный ключ клиенту — он вводится в приложении в поле «Ключ».
