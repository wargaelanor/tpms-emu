# TPMS Emulator / Sniffer v7.3

ESP32-C3 + CC1101 сниффер TPMS и ESP8266 + CC1101 эмулятор TPMS для **Acura RDX 2008** (датчики PMV-107J, 315 MHz).

![ESP32-C3](ESP32-C3-super-mini.jpg)

## Возможности

- **Эмулятор 4 датчиков** — имитация PMV-107J TPMS (315 MHz)
- **Приём реальных датчиков** — приём и декодирование настоящих передач PMV-107J
- **Web интерфейс** — настройка всех параметров с телефона/ПК
- **OTA обновления** — прошивка по WiFi без USB
- **Питание от батареи** — deep sleep с контролем напряжения (18650 Li-Ion)
- **Система лицензий** — 24 часа пробный период, затем нужен ключ

### ESP32-C3 Mini → CC1101 Подключение

```
ESP32-C3 Pin        →  CC1101 Pin       Назначение
──────────────────────────────────────────────────────
GPIO6               →  Pin 1 (VCC)      Питание (напрямую от GPIO!)
GND                 →  Pin 2 (GND)      Земля
GPIO1 (FSPI MOSI)   →  Pin 3 (SI/DIN)   SPI MOSI
GPIO3 (FSPI MISO)   →  Pin 4 (SO/DOUT)  SPI MISO
GPIO2 (FSPI SCK)    →  Pin 5 (CLK)      SPI Clock
GPIO7               →  Pin 6 (CSN)      Chip Select
GPIO4               →  Pin 7 (GDO0)     GDO0
GPIO5               →  Pin 8 (GDO2)     GDO2
```

### ESP8266 D1 Mini → CC1101 Подключение

```
ESP8266 Pin         →  CC1101 Pin       Назначение
──────────────────────────────────────────────────────
D4 (GPIO2)          →  VCC через N-MOSFET  Питание (через MOSFET)
GND                 →  Pin 2 (GND)      Земля
D6 (GPIO12 / HSPI)  →  Pin 3 (SI/DIN)   SPI MOSI
D7 (GPIO13 / HSPI)  →  Pin 4 (SO/DOUT)  SPI MISO
D5 (GPIO14 / HSPI)  →  Pin 5 (CLK)      SPI Clock
D8 (GPIO15)         →  Pin 6 (CSN)      Chip Select
D1 (GPIO5)          →  Pin 7 (GDO0)     GDO0
D2 (GPIO4)          →  Pin 8 (GDO2)     GDO2
```

### Делитель напряжения батареи (обе платы)

```
18650 (3.0-4.2V) → [10kΩ] → пин ADC → [10kΩ] → GND

Формула: Vbat = ADC_reading × 2

Vbat    Vout    Статус
──────────────────────
4.2V    2.1V    Полный заряд
3.7V    1.85V   Номинал
3.3V    1.65V   ПРЕДУПРЕЖДЕНИЕ (LOW)
3.0V    1.5V    КРИТИЧНО — устройство отключается
```

### Подключение Deep Sleep

- **ESP8266**: Припаять D0 (GPIO16) → RST (обязательно для пробуждения)
- **ESP32-C3**: Пробуждение по таймеру (дополнительная проводка не нужна)

### Схема питания (для каждой платы)

```
[18650] → [TP4056] → [DW01+FS8205] → [AMS1117-3.3] → [ESP] → [CC1101]
 3.7V     зарядка    защита          стабилизатор 3.3V
```

## Сборка

### Требования

- [PlatformIO](https://platformio.org/) (плагин VS Code или CLI)
- USB кабель (только для первой прошивки)

### Команды сборки

```bash
# ESP32-C3 сниффер
pio run -e esp32-c3-devkitm-1

# ESP8266 эмулятор
pio run -e esp8266-d1mini
```

### Команды прошивки

```bash
# ESP32-C3 (COM3)
pio run -e esp32-c3-devkitm-1 -t upload --upload-port COM3

# ESP8266 (COM8)
pio run -e esp8266-d1mini -t upload --upload-port COM8
```

> **Внимание**: После прошивки ESP32-C3 нужно нажать кнопку RST на плате.

## Использование

### Web интерфейс

1. Включите устройство
2. Подключитесь к WiFi: **TPMS** / `12345678`
3. Откройте браузер: `http://192.168.4.1`

### Serial команды

| Команда | Описание |
|---------|----------|
| `n` | Старт/стоп сниффера |
| `s` | Широкий частотный скан |
| `t` | Тест эха |
| `r` | Сброс таймера лицензии |

### Поведение

- **Первые 3 минуты**: WiFi AP активен, web интерфейс доступен
- **После 3 мин (нет подключения)**: устройство уходит в deep sleep между передачами
- **При пробуждении**: send burst → deep sleep (без WiFi)
- **Критический уровень батареи (< 3.0V)**: устройство прекращает передачу

## Протокол — PMV-107J

| Параметр | Значение |
|----------|----------|
| Модуляция | 2-FSK (mod=0) |
| Скорость | 10 kbps |
| Девиация | 38 kHz |
| Кодирование | Differential Manchester |
| Преамбула | 0xFC (11111100, 8 бит) |
| Пакет | 8 бит преамбулы + 68 DM бит = 144 бита в эфире |
| Частота | 315.000 MHz |

### Структура пакета

```
[8 бит преамбулы][68 DM-закодированных бит]
  ↓
[28 бит ID][1 бит bat][2 бит cnt][1 бит 0][1 бит rapid][1 бит fail]
[8 бит P][8 бит !P][8 бит T][8 бит CRC]
```

CRC-8: poly=0x13, init=0x00, по первым 58 битам

## Система лицензий

- **Пробный период**: 24 часа (сбрасывается при каждой прошивке)
- **Лицензионный ключ**: 8 hex символов
- **ESP8266**: Принимает любой валидный hex ключ
- **ESP32-C3**: Проверка HMAC-SHA256
- **Истечение срока**: питание CC1101 отключается, устройство уходит в deep sleep
- **Контакт**: wargaelanor@yandex.ru
